# About this app

{{ site.title }} lets you write notes, organise them with **tags** and **categories**, work on many at once with **multi-select**, and **share them by email**. It's also a playground for a modern delivery setup:

- **Frontend:** static pages generated by [Jekyll](https://jekyllrb.com/) from the `frontend/` folder.
- **Backend:** a [FastAPI](https://fastapi.tiangolo.com/) app serving the pages and a JSON API under `/api`.
- **Feature flags:** [Cloudflare Flagship](https://developers.cloudflare.com/flagship/) decides what each visitor sees. Your current flags are at [`/api/flags`](/api/flags).
- **Delivery:** GitHub Actions tests the code, builds a Docker image and publishes it.

## API

| Endpoint | What it does |
|---|---|
| `GET /health` | Health check |
| `GET /api/flags` | Feature flags for the current visitor |
| `GET /api/notes` | List notes (filter with `tag`, `category_id`, `q`) |
| `POST /api/notes` | Create a note: `{"text": "...", "tags": ["work"], "category_id": 1}` |
| `PATCH /api/notes/{id}` | Edit a note |
| `POST /api/notes/bulk` | Change or delete several notes at once |
| `POST /api/notes/share` | Prepare an email with chosen notes |
| `GET/POST /api/categories` | List or create categories |
| `GET /api/tags` | Tags in use |
| `DELETE /api/notes/{id}` | Delete a note |

Interactive API docs are at [`/docs`](/docs).
